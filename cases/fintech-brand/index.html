05

Правила

Короткий чек-лист для дизайнеров и подрядчиков.

✓ Так

Оставлять охранное поле не меньше высоты точки. Использовать лайм только для действий и успешных статусов.

✕ Не так

Растягивать, поворачивать знак, ставить лайм на белый фон, писать суммы не моноширинным шрифтом.
